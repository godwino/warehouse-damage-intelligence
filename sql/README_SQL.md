# SQL Analytics Layer

## Purpose of the SQL Layer
This SQL layer extends the Warehouse Damage Intelligence project with SQL Server scripts for loading and analyzing the synthetic warehouse damage dataset. It gives analysts and managers a second way to explore damage trends outside the Streamlit app.

## How to Create the Table
1. Open SQL Server Management Studio.
2. Select the target database.
3. Run `sql/create_warehouse_damage_table.sql`.
4. Confirm that the `warehouse_damage` table was created successfully.

## How to Import the CSV into SQL Server
You can import `data/warehouse_damage_data.csv` into SQL Server in either of these ways:

1. Use the SQL Server Import Wizard and map the CSV columns to the `warehouse_damage` table.
2. Use the commented `BULK INSERT` example in `sql/create_warehouse_damage_table.sql` after updating the file path.

The CSV is generated by `generate_data.py`, so make sure the file exists before importing.

## How to Run the Analysis Script
1. Confirm the `warehouse_damage` table contains data.
2. Open `sql/warehouse_damage_analysis.sql`.
3. Run the script section by section or execute the full file.
4. Review the result grids for KPI summaries, hotspots, risk factors, and action lists.

## What Business Questions the SQL Answers
- Which process area has the highest damage cost?
- Which SKUs should management investigate first?
- Which categories have the highest damage rate?
- Which aisles are damage hotspots?
- Which equipment types and damage sources are most involved?
- What are the highest-priority corrective actions?
- What savings are possible if damage cost is reduced by 10%, 15%, or 20%?

## Example Insights a Manager Can Get
- Identify which process area contributes the most damage cost.
- Find the SKUs and categories creating the largest financial impact.
- Detect which aisles have elevated damage rate or damage cost.
- See whether congestion, pallet stability, equipment condition, or slotting risk align with higher damage.
- Review the top 20 high-priority records and their suggested corrective actions.
- Estimate the financial value of damage reduction scenarios.

## Disclaimer
This project uses fully synthetic data for demonstration and portfolio purposes. It does not contain real company information, real warehouse records, real employee details, or confidential operational data.
